# HEYYANIXX Upscale

Free, 100% in-browser video enhancer: AI upscale (2x / 4x neural-net shaders on WebGPU), Fast Enhance (WebGL) for any phone, pro reel-style colour grades, AE-style effects, 60fps smooth (frame blend) and H.264 MP4 export with the original audio.

**Videos never leave your device** — no upload, no server.

Live: https://heyyanixx.github.io/heyyanixx-upscale/
